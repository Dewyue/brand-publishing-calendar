# 品牌发布日历

纯前端发布提醒与记录工具，打开 index.html 即可使用。

- 每个日期分左右两栏：左边小红书，右边公众号。
- 每周一、三、五默认展示小红书（洋葱、灵知）和公众号（洋葱、八分、灵知），2026-11-25 之前共五项任务，从 2026-11-25（含）起小红书也包含八分，共六项任务；其他日期也可点击平台下的加号添加。
- 蓝色洋葱雅思、黄色八分雅思、紫色灵知雅思。点击品牌格后只填一行文件名称或内容描述，可切换品牌。
- 勾选方框标记已发布，再次点击撤销；顶部今日清单与月历同步。
- 日历编辑窗口或看板明细可删除发布，确认后从日历、今日清单和统计中移除；默认任务不会重新出现。
- 数据保存在当前浏览器，支持导出与合并导入 JSON 备份，不跨设备自动同步、不自动发布到平台。
- 自动迁移上一版真实记录，忽略上一版示例内容；旧数据仍保存在原来的存储位置。
- 今日清单始终展示所有品牌，月历品牌筛选仅影响月历。

无需安装、构建或服务器。源代码公开保存在 GitHub，网页由 GitHub Pages 托管。

八分雅思小红书从 2026-11-25（含）起恢复排期和新增，之前日期保持原规则；已删除的任务不会自动恢复。

## 数据看板与备份

顶部切换“数据看板”可查看已发布数、已填内容待发布数、发布天数、最近发布日期，以及品牌 × 平台统计和发布明细。支持本月、全部时间、自定义日期、品牌、平台筛选，以及明细状态和名称搜索。明细可导出为 CSV；明细搜索和状态筛选仅影响明细及其导出，顶部指标与品牌统计按日期、品牌、平台计算。

统计按日历中的发布日期计算，勾选即计为已发布；空白默认提醒不计入统计。历史八分小红书记录保留在看板中。新勾选记录会附带完成时间，旧记录不会虚构时间。

顶部“导出备份”导出所有数据（JSON，含隐藏历史记录），与看板筛选无关。“导入备份”先验证文件并预览记录数和冲突数，确认后下载一份导入前备份，再合并；相同日期、品牌和平台使用导入记录，本地其他记录保留。支持此前版本导出的 version 2 备份。

删除标记会保存在备份中，导入后仍生效。若需重新添加，可点击相应日期平台的加号，选择品牌后保存。
